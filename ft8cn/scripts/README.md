# Asset Preprocessing Scripts

This directory contains scripts to pre-process JSON assets into SQLite databases for improved performance and reduced APK size.

## Overview

The app can load data from either:
1. **Pre-processed SQLite files** (faster, smaller) - `ituzone.db`, `cqzone.db`, `dxcc_list.db`
2. **JSON files** (fallback) - `ituzone.json`, `cqzone.json`, `dxcc_list.json`

The app automatically detects and uses pre-processed SQLite files if available, falling back to JSON parsing if not found.

## Benefits

- **Faster startup**: SQLite databases load much faster than parsing large JSON files
- **Smaller APK size**: SQLite databases are typically 30-50% smaller than equivalent JSON
- **Better performance**: Direct SQL queries instead of JSON parsing

## Usage

### Option 1: Manual Preprocessing (Java)

The `PreprocessAssets.java` script can be compiled and run to generate SQLite databases:

```bash
# Compile (requires org.json library)
javac -cp "path/to/json.jar" PreprocessAssets.java

# Run
java -cp ".:path/to/json.jar" PreprocessAssets \
    ../app/src/main/assets \
    ../app/src/main/assets
```

### Option 2: Gradle Task (Recommended)

Add to `app/build.gradle`:

```groovy
task preprocessAssets(type: JavaExec) {
    classpath = sourceSets.main.runtimeClasspath
    main = 'com.bg7yoz.ft8cn.scripts.PreprocessAssets'
    args = [
        "${projectDir}/src/main/assets",
        "${projectDir}/src/main/assets"
    ]
}

// Run before assemble tasks
preBuild.dependsOn preprocessAssets
```

### Option 3: External Tool

You can use any tool that converts JSON to SQLite. The expected schema is:

**ituzone.db:**
```sql
CREATE TABLE ituList (itu TEXT, grid TEXT);
```

**cqzone.db:**
```sql
CREATE TABLE cqzoneList (cqzone TEXT, grid TEXT);
```

**dxcc_list.db:**
```sql
CREATE TABLE dxccList (
    id INTEGER, dxcc INTEGER, cc TEXT, ccc TEXT, name TEXT,
    continent TEXT, ituzone TEXT, cqzone TEXT, timezone INTEGER,
    ccode INTEGER, aname TEXT, pp TEXT, lat REAL, lon REAL
);
CREATE TABLE dxcc_grid (dxcc INTEGER, grid TEXT);
CREATE TABLE dxcc_prefix (dxcc INTEGER, prefix TEXT);
```

## File Placement

Place the generated `.db` files in `app/src/main/assets/` alongside the JSON files:

```
app/src/main/assets/
├── ituzone.json
├── ituzone.db          # Optional, generated by preprocessing
├── cqzone.json
├── cqzone.db           # Optional, generated by preprocessing
├── dxcc_list.json
└── dxcc_list.db        # Optional, generated by preprocessing
```

## Notes

- The app will automatically use `.db` files if present, otherwise fall back to `.json`
- Both formats can coexist - the app prefers SQLite
- The preprocessing step is optional - the app works fine with just JSON files
- SQLite files should be regenerated if JSON source files are updated
